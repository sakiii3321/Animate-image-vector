# 图片转 SVG · 独立版

从 GitHub 克隆后，请先按 [源码安装说明](README.md) 配置依赖。下文的便携包步骤要求另有完整运行库；历史 `outputs/`、测试原图和评分记录不包含在源码仓库中。

这是使用 Potrace 进行色块描摹的本机程序，提供边缘清理、渐变分层、平涂分层与传统 Potrace 四种重构方案。基础转换不需要 ComfyUI、PyTorch、GPU、Wand 或 ImageMagick；超分辨率与 DiffVG 后处理使用可选的本机增强运行时。界面使用系统浏览器，但计算在本机，不会上传图片，不依赖在线网页或 CDN。

## 预设与高级模式

主界面默认显示五个预设，选好图片后可直接采用并转换。裁剪与保存位置始终可以单独设置；只有打开 **高级模式** 才显示完整的分色、曲线、超分与后处理参数。

| 预设 | 路径预算 / 初始分色 / 曲线容差 | 用途与取舍 |
| --- | --- | --- |
| 均衡插画（默认） | 2000 / 100 / 0.3 | 边缘清理路线，作为通用起点。 |
| 细节优先 | 4000 / 160 / 0.2 | 给小色块与细线更多预算，耗时和文件体积可能增加。 |
| 轻量简洁 | 800 / 64 / 0.5 | 减少配色与路径，细小花纹可能被简化。 |
| 柔和渐变 | 2000 / 64 / 0.3 | 渐变分层路线，尝试用渐变表达大色面明暗。 |
| 线稿 | 1500 / 64 / 0.2 | 边缘清理路线、较少分色与较低简化容差，保留原色，不自动转黑白。 |

这些预设是可调整的起点，新增参数组合未经过新一轮人工盲评。点击预设会保留裁剪与输出位置，重置其他转换参数，并关闭超分、DiffVG 和高分辨率补充优化。需要增强时在高级模式中自行开启。手动修改后摘要显示 **自定义**；关闭高级模式仅收起控件，不会丢弃设置。高级模式提供配置导入、导出与恢复默认；既有 JSON 配置继续按原来的兼容规则载入。

## 独立裁剪窗口

选图后点击 **编辑裁剪**，在独立窗口中移动选框或拖动四角。支持 **16:9、9:16、4:3、3:4、1:1、自定义比例**，也可以自由调整宽高。固定比例下，四角拖动保持比例；自由比例下，宽高可独立改变。选框不会超出原图，窗口显示最终像素尺寸。

点击 **应用裁剪** 才会提交；取消、关闭或按 Escape 保留之前的范围。切换图片时清除旧图的具体选框，防止坐标误用于新图。分析建议与实际转换使用同一个已提交范围，裁剪发生在超分和矢量化之前，原始文件不会被修改。

## 插画方案与图片分析（2026-11-06）

新启动的程序默认使用 **Potrace → 边缘清理**，路径上限 2000，初始分色 100，曲线简化开启、容差 0.3。这是第二轮盲评中较稳的通用路线。渐变分层的总平均分更高，但复杂纹理、线稿并非始终受益，因此保留为可选方案。

| 方案 | 处理方式与适用情况 |
| --- | --- |
| 边缘清理 · 通用 | 轻度保边平滑，清理边缘抗锯齿混色碎片，连接相近细区域，再拟合连续曲线。优先用于线稿、平涂和复杂插画。 |
| 渐变分层 · 柔和上色 | 先生成大色块，检查重构误差，再补线和补色；在通过独立像素误差检验的色面上拟合 SVG 线性渐变。 |
| 平涂分层 · 实验 | 同样分层补线与补色，不拟合渐变，保留作比较。 |
| 传统 Potrace · 兼容旧配置 | 保持此前生产版分区/描摹流程和原参数语义。 |

选图后会分析当前裁剪范围，显示画风倾向、复杂度、相对清晰度和内容分布。点击 **采用建议** 才会应用推荐方案与路径预算，不自动开启超分。构图只描述方向与内容分布，不识别人脸、眼睛或角色，也不自动裁剪。清晰度信号不能区分所有模糊、抗锯齿和柔和画风；推荐仍需检查局部效果。

高级模式中的“插画重构方案”选择底层路线，切换时保留超分、裁剪与输出位置；它与主界面完整预设的重置范围不同。新路线内部已有固定的两次轻度保边滤波，所以额外的 `potrace_smoothing` 默认是 0。路径总预算包括填色与补线；设置更小的“目标绘制路径数”时，新路线从分区开始使用较小预算，避免重复分区和再次简化。高色差与邻接关系参与合并判断，但预算过低仍可能丢失细节，无法保证保留所有小图案。

旧 Potrace JSON 配置不带 `illustration_profile` 时，保留传统路线；不会悄悄换成新方案。VTracer 已移除，旧 VTracer 配置会明确报错，详细迁移规则见下文“配置兼容”。新配置可导入 `examples/illustration-edge-clean.json`、`illustration-gradient-layers.json`、`illustration-flat-layers.json`。命令行只指定 `illustration_profile` 也会载入对应预设，显式提供的其他参数优先。

分层方案支持超分辨率预处理（GPU 优先，失败回退 CPU），暂不与 DiffVG 全图或高分辨率补充优化组合，以保留开放描线和渐变。边缘清理与传统 Potrace 继续支持原增强流程。新路线每次保存 `.pipeline.json`，记录实际参数、分阶段耗时、路径数与渐变拟合；过程位图位于任务临时目录，完成或失败后清理。

本次曲线简化优化只减少重复采样和解析，不改变拟合容差；4 个真实 SVG 抽样的交错测试耗时减少约 25%–29%，输出字节一致。这是曲线简化阶段的结果，不代表整次转换同幅度加速。验证与整套图片回归记录位于 `outputs/software-optimization-study/`，可控性能基准位于 `outputs/performance-geometry-study/benchmark.json`。本次没有新增一轮人工评分。

## 转换后的圈画精修

转换成功后，对比画布上方会出现 **局部精修** 面板。适合补回眼白、鼻翼、嘴部、衣服图案等在初次分区中被合并掉的细节；算法不识别五官，只根据圈内原始像素重新分色和描摹。

1. 先放大并拖到要检查的位置，拖动分界线比较原图与当前 SVG。
2. 点击 **圈画区域**，按住鼠标或触笔画出简单闭合轮廓，松开后自动闭合。圈线尽量落在较平坦的颜色区域，给要恢复的细节留一点余量。圈画时暂停缩放和平移，退出圈画后可以继续调整视角。
3. 选择局部路径预算（默认 **300**，范围 **50–1500**）和“标准 / 更精细”，点击 **生成候选**。预算只分配给本次局部；更精细使用更多初始颜色与更低曲线容差，不会凭空增加原图没有的信息。
4. 切换 **原结果 / 候选（未采用）** 检查效果。候选仅在内存中，下载仍对应已保存的当前结果；不满意可放弃或修改参数重新生成。停止新一轮生成时，已有候选和已保存结果保留。
5. 点击 **采用并保存新 SVG**，另存新文件及同名 `.pipeline.json`，不覆盖原文件。可以继续圈画其他位置。当前页面支持撤销最近 **3 次采用**，撤销不删除已保存的版本文件。

局部重建读取本次转换的规范化、裁剪后原图；即使全图使用过超分，圈选也以最终画布的原图像素定位，不重复执行超分或整图优化。局部计算包含圈外 12 像素上下文，最多处理 150 万像素、长边 2048 像素，过大时会提示缩小圈选，不偷偷降低分辨率。

输出仍为纯矢量。旧矢量内容保留，局部补充用矢量裁剪限定范围；圈内原图像素全部不透明时，保留旧颜色作为底衬，避免色块之间的抗锯齿缝隙露白；只要圈内存在透明或半透明像素，就采用选区替换以保持透明度。圈线附近可能有很窄的抗锯齿过渡，应放大检查；不满意可以撤销。新增路径单独计入文件总数，因此精修后可能超过初次全图路径上限，被遮挡的旧路径也仍计数。

选择新图片或重新整图转换会开始新的精修会话。刷新或关闭页面前应采用并保存需要的结果；候选和撤销操作不作为可重新打开的工程文件持久保存。保存已经完成但预览读取失败时，会明确提示并禁用旧内容下载，可点击 **重试预览** 恢复显示。

## Windows 便携版

1. **完整解压 ZIP** 到可写目录，不要在压缩软件内部直接运行。
2. 双击根目录的 `START_WINDOWS.bat`；会出现控制台并自动打开浏览器。
3. 选择图片，按需打开独立裁剪窗口拖动选框和四角，并点击应用。选择一个预设后点击「转换为 SVG」；详细参数可在高级模式中调整。程序会先按已提交的选框裁剪，再执行超分与矢量化。SVG 画布使用选框显示的像素尺寸。
4. 成功后显示 SVG 预览及实际保存路径；「另存 SVG 副本」使用浏览器下载功能。
5. 完成后回到控制台按 **Ctrl+C**。仅关闭网页不会退出后台。

没有自动打开浏览器时，复制启动窗口打印的完整 `http://127.0.0.1:端口/?token=...` 地址到浏览器。不需要安装浏览器扩展。请勿分享此含访问令牌的本机地址。

便携版面向 Windows x64。Windows ARM 设备是否支持 x64 仿真取决于系统；不包含原生 ARM 包。当前版本已用随包 Windows 运行时完成 Potrace 转换测试及 Chrome 界面测试，记录位于 `tests/results-potrace-windows.txt` 和 `tests/potrace-ui-results.json`。

## Potrace 连续色块与路径上限

1. 更新后重新启动 `START_WINDOWS.bat`，在「插画重构方案」选择需要的 Potrace 路线。
2. 设置「绘制路径总上限」，范围 **1–20,000**；边缘清理默认 **2,000**，传统路线预设 **2,500**。这是硬上限，简单图片可能只用更少的路径。输出时会重新检查实际 SVG 路径数，超限不会保存。
3. 可填写「细节优先区域」：`x,y,宽,高`，使用经 EXIF 规范化后的原图像素坐标；留空为全图均等。对本次 2285×3753 测试图，眼区可填 `780,795,270,245`；不要将这个坐标套用到其他尺寸图片。
   启用裁剪时仍填写完整原图坐标。部分重叠时仅保留交集，完全在选框外时会提示调整。
4. 转换成功后，输出区显示实际填充路径数、轮廓数（包括孔洞）和线/曲线段数。数量与画质应一起比较。

Potrace 流程先做颜色分区，再合并相邻近似颜色，最后用平滑闭合曲线描摹每个连通色块。分色阶段保留已初始化的少量颜色簇，以保护细线和小高光。预算合并以 Lab 感知色差为基础；传统路线使用平方根面积权重，新插画路线使用 0.75 次幂，兼顾小细节与大色面失真。传统路线初次描摹和后处理目标色块简化使用同一策略。面积清理仅作用于与邻区色差很小的小块（Lab 与透明度联合距离不超过 6）。细节优先区域有更高权重。路径预算很低时，仍需在细节之间取舍。

对于眼白、袜子圆点等颜色接近背景但形状清楚的细节，可勾选 **插画结构保护（实验）**。它从 Lab 多阈值连通区域中，依据局部对比、紧致度和内部颜色一致性筛选封闭小图案，在初始分区、面积清理及后续色块合并中保留候选边界。模式中面积权重指数调整为 0.75，以兼顾大色面的颜色误差。它是几何规则，不是眼睛或服装识别模型；可能漏检，也可能保留不需要的纹理，因此默认关闭，便于对比。

结构保护使用裁剪后的原图检测，启用超分时仅将检测区域映射到超分尺寸；不从生成的纹理判断原图结构。候选最多为 256 个，并随初始路径预算调整；超过 800 万像素时缩小检测图。候选同样计入路径上限，如果预算不足，仍允许跨候选边界合并。不会用嵌入位图或合并不连通路径规避数量约束。

跨图片测试覆盖 `test_pic` 中全部 8 张图片，包括原尺寸和半尺寸的 40 次转换；同一方法固定参数，不按图片指定 ROI 或保护位置。通用配置位于 `outputs/illustration-generalization-study/config-structure.json`，对照结果见同目录 `report.html`。线稿、低清图片和复杂纹理仍可能出现退步，保留实验功能默认关闭。此前单图测试保存在 `outputs/illustration-structure-study/`，其中带裁剪的配置不应当作通用设置。

此前人工盲评为每张原图提供四份匿名 SVG，可同步缩放和导出评分；各候选未统一路径数量，先评视觉质量，再揭盲分析复杂度。旧盲评页面现已归档，生成的 SVG 与预览图已清理。需要重新开展盲评时，请使用 `experiments/` 中的工具、自备测试图片并重新生成候选；先完成盲评再查看具名报告，以减少预先知道方法和指标对评分的影响。

相邻区域合并已采用区域均值缓存、标量代价计算、局部邻接更新和失效队列清理，避免反复创建小数组及积累过期候选。初始 Potrace 分区与后处理目标色块简化均使用此优化；细节区域权重、透明区域隔离和数量约束保持原有规则，不需要新增依赖或额外开关。实际耗时仍取决于初始碎片数量、图片尺寸及配置。

曲线拟合默认使用 optTolerance=0.4、alphaMax=1，并采用同色 1px 描边缓解独立区域边界的细缝；描边会轻微扩张轮廓。开启描边时大色块先画，小细节后画，降低背景描边覆盖细线的风险。以下参数现在可以在界面调整。透明度按区域近似保留，完全透明区不生成填充路径。如果透明背景把图片分成的独立区域数已经超过上限，会明确报错，需提高上限。

可直接导入 `examples/potrace-config.json`；本次测试图的眼区配置见 `examples/potrace-eye-study.json`。这些示例显式使用传统 Potrace；新的默认示例是 `examples/default-config.json`。

### Potrace 可调参数

新增选项分为「曲线描摹」与「色块分区」。下表列出当前边缘清理默认值，并注明与传统路线的差异；旧 Potrace JSON 继续按传统预设补齐缺省字段。鼠标悬停参数名称可查看具体作用、取舍及适用条件，也可通过键盘聚焦或点击帮助标记查看。

| 界面选项 / 配置键 | 默认值与范围 | 对重构的主要影响 |
|---|---|---|
| 描摹线程数 `potrace_trace_threads` | 0；0–16，整数 | 0 自动：较大任务最多 4 线程，小任务单线程；1 强制单线程，2–16 指定期望线程数。实际数量受 CPU、可用内存及色块数限制，进度显示实际值。仅并行描摹各色块，不并行相邻色块合并；SVG 使用统一绘制顺序。 |
| 角点阈值 `potrace_alpha_max` | 1；0–1.5，步长 0.1 | 越小越容易保留尖角；0 输出多边形，超过 4/3 时全部平滑。 |
| 内部曲线合并 `potrace_opt_curve` | 开启 | 在描摹阶段合并相邻贝塞尔曲线段；与 SVG 生成后的曲线简化独立。 |
| 曲线合并容差 `potrace_opt_tolerance` | 0.4；0–2，步长 0.05 | 容差越大通常允许合并更多曲线段，但轮廓偏差可能增大；仅内部曲线合并开启时生效。 |
| 边界连接策略 `potrace_turn_policy` | black；传统路线 minority；6 种策略 | 决定对角接触等歧义边界如何连接，可改变细线连接和孔洞。 |
| 小轮廓删除阈值 `potrace_turd_size` | 0；0–100，整数 | 直接删除指定面积以内的轮廓，可能丢失色块或孔洞；默认 0 保留，通常优先调整上游小色块合并。 |
| 初始分色数量 `potrace_palette_colors` | 100；分层 64、传统 48；2–256，整数 | 用于初始颜色聚类，增加时可保留更细的颜色差异，也可能产生更多碎片与更长耗时；并非最终填充路径数或最终颜色数。 |
| 插画结构保护 `potrace_preserve_structure` | 关闭；布尔值 | 优先保留检测到的封闭小图案，兼顾大色面颜色误差。适合低对比圆点、眼白等；实验功能，可能误检，不保证保留所有细节。 |
| 预平滑强度 `potrace_smoothing` | 0；传统路线 1；0–3，步长 0.1 | 0 跳过预平滑；增大可压制纹理与杂点，也可能抹去发丝等细节。 |
| 近色小块清理 `potrace_min_region_area` | 8；传统路线 16；0–1024，整数 | 仅优先清理与邻区颜色很接近的小块。高色差小块进入按感知色差和温和面积权重排序的预算合并阶段。设为 0 关闭面积清理，细节优先区域使用其一半面积阈值。 |
| 细节区域权重 `potrace_detail_weight` | 15；1–50，整数 | 增大后更倾向保留指定区域的差异，有限路径预算会相应偏向该区域；未设置区域时不起作用。 |
| 边界描边宽度 `potrace_stroke_width` | 1；0–3，步长 0.1 | 同色描边缓解细缝，也会扩张轮廓；0 关闭描边。 |

长度以原图像素、面积以原图像素面积设置；启用超分后分别按倍数和倍数平方转换，输出归一到超分前的画布。使用细节区域时，初始分色预算按约 2/3 全局、1/3 局部分配，具体数量随所选初始分色数量变化。可导入 `examples/potrace-advanced-config.json` 查看传统路线的完整示例，或导入三个插画方案示例。最终填充路径数继续受硬上限约束。

Potrace 原生参数参考 [node-potrace](https://github.com/tooolbox/node-potrace#parameters) 和 [Potrace 手册](https://potrace.sourceforge.net/potrace.1.html)。初始分色、平滑、区域合并、细节权重和描边宽度由本程序实现。

## 可选预处理与后处理

界面按「预处理 → 矢量化 → 后处理」排列，旧配置默认关闭所有增强功能。

- **超分辨率预处理**：可选 2× / 4×，使用 Real-ESRGAN AnimeVideo-v3。生成超分图后重新矢量化，保留透明通道。图片最多 4000 万输入像素；超分后的总像素不得超过 1.6 亿，超限会明确提示，不会偷偷降低倍数。倍数作用于宽和高，例如 1866 万像素图片可使用 2×；4× 会超过超分输出上限。
- **曲线简化**：可独立开启，默认容差 0.3 个原图像素，可设 0.1–2.0。合并冗余曲线，保留强转角锚点。它不需要 PyTorch。
- **目标绘制路径数**（`simplify_target_paths`）：勾选曲线简化时生效，范围 0–20,000，默认 0 不额外约束。新插画路线从分区开始采用它与路径上限中较小的正数预算，包含填色和补线；传统路线继续合并相邻色块、重新描摹并简化曲线。已有路径少于目标时不增加；透明背景隔开的区域不会打包，无法达到目标时会提示。数量越小越可能丢失细节。
- **DiffVG 全图优化**：可独立开启，默认 30 轮，可设 1–100 轮。全部色块参与，使用全画幅目标（长边最高 1024，保持比例，小图不放大）。
- **高分辨率补充优化**：边缘清理与传统路线启用超分辨率时默认勾选，可手动取消；分层路线不支持此步骤。关闭超分辨率会取消并禁用它。修改超分倍数不会覆盖你手动取消的选择。它可独立于普通全图优化运行，在超分图实际像素尺度按格覆盖整张图，共享同一组矢量参数。

开启超分辨率后，DiffVG 的拟合目标是超分图；未开启时使用规范化原图。输出 SVG 使用超分前的画布尺寸。启用裁剪时，预览和 SVG 均以选框左上角为原点。预览可切换「原图 / 预处理图」与最终矢量对照。转换时显示当前阶段及已处理的轮数或格数。

生成过程中可点击转换按钮旁的「停止」。程序会终止当前任务及其 Potrace、超分辨率、DiffVG 子进程，等待退出后恢复配置编辑；所选图片和参数保持不变，可修改后重新生成。停止不会保存未完成的 SVG，也不会删除先前结果。最终文件开始保存后，停止请求将提示等待保存结果。此按钮不用于停止引擎自检。

配置导入若包含 `sr_enabled: true` 且省略 `highres_refine`，边缘清理与传统路线默认开启高分辨率补充，分层路线保持关闭；显式 `false` 会保留。没有超分辨率却指定 `highres_refine: true` 会明确报错。完整示例见 `examples/enhanced-sr-config.json`，仅超分示例见 `examples/sr-only-config.json`。

Potrace 的像素相关预处理、细节区域坐标和描摹参数按超分倍数缩放；路径上限仍是原设置。后处理报告记录各阶段的真实路径、曲线段与控制节点数量，与 SVG 一起保存为同名 `.pipeline.json`。

早期增强功能的测试与 Chrome 验证记录保留在 `tests/enhancement-validation-summary.json`、`tests/enhancements-ui-results.json`；它们记录当时版本，不代表当前支持的引擎清单。新插画路线的真实 SR 集成结果见 `outputs/software-optimization-study/sr-integration/report.json`。

### 增强运行时

本机已配置 `runtime/enhancement/config.json` 指向现有 Python 3.12 / PyTorch 环境。超分模型、DiffVG CPU 扩展和补充依赖已放入 `runtime/enhancement/`，不再从实验输出目录读取。

超分辨率默认优先使用 **NVIDIA CUDA GPU（FP16）**，无需手动选择设备。未检测到可用 CUDA、GPU 初始化失败、显存不足或 GPU 推理失败时，自动使用 **CPU（FP32）**；中途失败会从原始模型权重重新处理整张图，保持所选倍数、分块设置和透明通道。界面显示优先设备、实际处理设备及回退状态，同名 `.pipeline.json` 记录实际设备和回退原因。损坏的模型、输入或输出文件错误仍会明确报错，CPU 重试失败也会保留错误。GPU 支持当前指 NVIDIA CUDA，其他显卡使用 CPU。

这项设备策略仅作用于超分辨率；当前 DiffVG 全图优化、高分辨率补充优化，以及 Potrace 描摹仍使用 CPU。超分功能本身仍由“超分辨率预处理”复选框开启。

**现有增强配置不是完整的跨电脑便携环境。** 把软件移到另一台电脑后，需要配置兼容的 Python 3.12 / PyTorch 环境；可修改上述 JSON 的 `python` 路径，或设置 `IMAGEVECTOR_ENHANCEMENT_PYTHON`。具体依赖和许可证见 `runtime/enhancement/README.txt` 与 `provenance.json`。基础转换与曲线简化不受可选运行时缺失影响，界面会显示增强能力诊断。

增强处理可能需要数分钟至更久；程序不会因缺少依赖而悄悄跳过所选步骤。DiffVG 无法忠实表示的半透明「填充+描边」整体分组会明确报错，避免改变透明效果；这类图片仍可只用超分辨率、矢量化和曲线简化。固定色块结构下，优化也不能保证恢复初始分区遗漏的全部细线。

## 配置兼容

当前只支持 `engine: "potrace"`。配置可在界面导入、导出，命令行可通过 `--config` 读取；「恢复默认」会恢复边缘清理方案和空的输出目录。完整参数说明见 `参数对照.md`。

- 新配置使用 `illustration_profile` 指定四种路线之一；显式参数优先于路线预设。
- 旧 Potrace 配置未包含 `illustration_profile` 时，保留传统参数与行为。
- 显式 `engine: "vtracer"`，或仅包含 VTracer 专属参数且未声明 Potrace / 插画方案的旧配置，会明确拒绝；不会自动改成另一种算法。
- 显式声明 `engine: "potrace"` 或包含有效 `illustration_profile` 的混合旧配置，会忽略遗留的 VTracer 专属字段，保留 Potrace 参数；显式 VTracer 引擎标识仍优先拒绝。新导出的配置不再包含那些字段。
- 其他未知字段、越界值或无效类型仍会明确报错。迁移旧 VTracer 配置时，请从 `examples/default-config.json` 或所需的 Potrace 示例重新开始；旧参数没有一一对应的自动换算关系。

## 输入与输出行为

- 支持 PNG、JPEG、WebP、BMP、TIFF、GIF；单文件最多 **20 MiB / 4000 万像素**。
- 多帧/多页图片只处理第一帧；自动应用 EXIF 方向，规范化为 8 位 RGBA PNG，保留透明通道。
- 浏览器原图预览显示原文件；动画可能播放，因此与实际转换的第一帧不同。透明图和高位深图与原 ComfyUI 上游张量预处理未必一致，不保证逐像素或 SVG 字节完全相同。
- 输出目录默认**空字符串**，与原节点一样使用系统临时目录。临时目录可能被系统清理，重要文件请指定自己的目录。
- 可填写完整路径，例如 `D:\MySVG`。也可使用相对路径，相对于启动程序的工作目录；启动批处理会切换到便携包根目录。文字 `temp` 不是特殊指令，而是普通相对文件夹名。
- 目录不存在时会创建。文件名使用输入名 + 随机唯一后缀；不覆盖已有文件。
- 每次转换生成一个 SVG；开启增强时另存阶段报告。预览只保留最近一次结果，但已保存的文件不会删除。
- 传统 Potrace 基础转换最多等待 1,200 秒；插画方案或曲线简化流程上限 2,700 秒，包含超分或优化的整条流程上限 10,800 秒。大图可能需要较长时间，界面会持续显示阶段进度。超过 64 MiB 的 SVG 不落盘。

## 常见问题

**程序启动后闪退 / 找不到运行库**：不要移动 `app`、`runtime` 等子目录。请保留完整解压结构。如系统报告缺少 Visual C++ 运行库，请只从 Microsoft 官方获取支持的 x64 运行库；不要下载来历不明 DLL。

**路径写入失败**：换成当前用户可写目录；不需要管理员权限。输出被其他程序锁定、磁盘不足等系统错误会显示在界面。

**颜色与原图不同**：这属于矢量化取舍。可以调整初始分色数量、路径预算与近色小块清理；照片比图标或平面插画通常产生更大的 SVG。

**转换引擎失败**：原配置不会被悄悄修改。native 引擎在独立子进程运行，失败后可继续更换图片或配置重试；错误内容可复制反馈。

python -m pip install -r requirements.txt

## 滑动对比预览

1. 选择图片，按需调整配置，然后点击图片信息下方的 **转换为 SVG**。转换成功后，左侧显示原图、右侧显示矢量。
2. 拖动中央圆形滑柄调整分界；拖到最左侧可看完整矢量，拖到最右侧可看完整原图。分界只裁切显示区域，不改变任何一侧的比例。
3. 滚轮或双指捏合以指针 / 手势位置为中心缩放；拖动画布平移。两侧共享同一坐标变换，方便检查相同位置的轮廓与细节。
4. **适应画布** 恢复完整图片视图；**1:1** 以源图片像素尺寸显示；**全屏** 放大预览工作区。
5. 在透明棋盘、白色与深色背景间切换，以检查透明区和边缘。**下载 SVG** 保存副本；**另一张图片** 选择新图片。

键盘：点击滑柄后，方向键每次移动分界 1%，Shift + 方向键移动 10%，Home / End 到两端。画布获得焦点时，+ / − 缩放、0 适应画布、1 恢复 1:1。

原图预览使用转换时同一份经 EXIF 方向规范化的 PNG；两侧采用相同宽高。SVG 尚未生成时不显示对比滑柄，下载按钮不可用。引擎问题可点击 **检查本机转换引擎**，原参数不会被自动修改。

预览交互的早期验证记录仍保留；Potrace 的 Windows 界面测试覆盖了数量上限、配置导入导出、实际 HTTP 转换和 SVG 预览。
